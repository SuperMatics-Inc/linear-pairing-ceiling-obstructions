## Relation to `STATIC-MODE` and `LINEAR4`--`LINEAR11`

   - **Theorems 1a, 1b, and 1c** settle this first-cumulant question in the affirmative: because $a_x(W)$ is a *conditional expectation inside a single static configuration* that enjoys the universal non-singular upper bound $a_x(W) \le \frac{U \Omega^2}{48 \tau^3}$ globally (`STATIC-MODE` eq.
